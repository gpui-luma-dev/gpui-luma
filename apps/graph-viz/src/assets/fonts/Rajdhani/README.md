# Rajdhani (Jarvis built-in theme only)

Bundled for the embedded `jarvis` theme when the gallery or Luma Studio runs with `jarvis`.

| File | Purpose |
|------|---------|
| `Rajdhani-Variable.ttf` | Single variable font (weights 300–700); GPUI family name **`Rajdhani Variable`** |
| `OFL.txt` | Full SIL Open Font License 1.1 (required; do not remove) |

**Source:** [Fontshare — Rajdhani](https://www.fontshare.com/fonts/rajdhani)  
**Copyright:** Indian Type Foundry (see `OFL.txt`)

The full Fontshare download (`Rajdhani_Complete/`) was trimmed to these two files; the license text in `OFL.txt` is unchanged from the upstream `License/OFL.txt`.
