Color Arc

Edit a color channel on a partial circular track.

Basic use

Hue arc with preview and commit
use gpui::{Context, Entity, Render, Window, div, prelude::*, px};
use gpui_luma::controls::slider::{SliderControl, SliderEventExt};
use gpui_luma_color::color_arc::ColorArcBuilder;
use gpui_luma_color::style::Size;

struct Example {
    control: Entity<SliderControl>,
    preview: f32,
    committed: f32,
}
impl Example {
    fn new(cx: &mut Context<Self>) -> Self {
        let control = ColorArcBuilder::hue("hue-arc", 210.0, 0.8, 0.5)
            .size(Size::Medium).start_degrees(-45.0).sweep_degrees(270.0)
            .spawn(cx)
            .on_value_changed(cx, |owner: &mut Self, _, value, cx| {
                owner.preview = value;
                cx.notify();
            })
            .on_release(cx, |owner, _, value, cx| {
                owner.committed = value;
                cx.notify();
            });
        Self { control, preview: 210.0, committed: 210.0 }
    }
}
impl Render for Example {
    fn render(&mut self, _: &mut Window, _: &mut Context<Self>) -> impl IntoElement {
        div().w(px(240.0)).child(self.control.clone())
    }
}

Channels and appearance

hue(id, hue, saturation, lightness), saturation(id, saturation, hue, hsv_value), and lightness(id, lightness, hue, saturation) choose the channel. Hue uses degrees; saturation/lightness use 0..1.

Use start_degrees and sweep_degrees for geometry, reversed for value direction, and size(Size), arc_thickness, and thumb_size for appearance. Raster rendering is the default; the *_with_renderer constructors accept ColorArcRenderer.

Register callbacks after spawn; use on_event or cx.subscribe for the full event stream. See Slider events.

Keyboard and synchronization

The arc uses the SDK Slider’s angular input strategy over a bounded start/sweep range. It does not enable the full ring’s wrapping policy. Use the normal SDK slider keyboard bindings and configure scalar step for channel snapping.

Retain domain_renderer() and track_context() before spawning. Update dependent color delegates and refresh thumb previews with update_arc_delegate / refresh_color_arc, or use the corresponding ColorCompositionSync helper. Numeric value changes alone do not update the base colors of the track.
