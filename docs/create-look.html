Create your own Look

Start with one control. Reuse its SDK behavior.

Start small

A Look can begin as an application helper. Keep your visual decisions together and return SDK control entities.

Local Look helper · integration snippet
use gpui::{prelude::*, Context, Entity, px};
use gpui_luma::controls::button::Button;
use gpui_luma::infra::presenter::HasPresenter;

fn action_button<M: 'static>(cx: &mut Context<M>) -> Entity<Button> {
    Button::new("action")
        .label("Continue")
        .with_template_modifier(|root, _| root.min_w(px(160.0)))
        .spawn(cx)
}

This customizes the fallback template’s geometry. It is a starting seam, not a complete visual system.
