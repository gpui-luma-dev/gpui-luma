Basic use

SDK · integration snippet
use gpui::{Context};
use gpui::{div, prelude::*};
use gpui_luma::controls::accordion::{self, AccordionItem, AccordionTrigger, AccordionContent};

struct Example {
    control: gpui_luma::controls::accordion::Accordion,
    details_expanded: bool,
}

impl Example {
    fn new(cx: &mut Context<Self>) -> Self {
        let control = accordion::new("details")
            .item(AccordionItem::new(
                "about",
                AccordionTrigger::new("About"),
                AccordionContent::custom(|_, _| div().child("Project details").into_any_element()),
            ))
            .on_expanded_changed(cx, |app, _, expanded, cx| {
                app.details_expanded = expanded;
                cx.notify();
            })
            .spawn(cx);

        Self { control, details_expanded: false }
    }
}

Integration snippet, checked against the current SDK and Radix crates. cx is the initialized owner context. The control retains its callbacks; callback owners are held weakly. Render self.control.clone() in the owner’s view.

SDK behavior & customization

The control owns expansion, dividers, and clipping. Frame supplies optional outer decoration.

Relevant contracts: AccordionItemRenderModel, AccordionRenderModel, AccordionTemplateModifier, AccordionTemplateHandlers.

Use the module’s template contract for structural changes. Builder modifiers and item templates vary by control.

Events

Callbacks follow the existing SDK event stream. Registrations append, hold the owner weakly, and live until the control is released. cx.notify() requests an owner redraw. Compound payloads are borrowed; scalar values are passed by value.

Event / payloadCallback
ExpandedChanged { item_id: SharedString, expanded: bool }.on_expanded_changed(cx, |app, item_id, expanded, cx| { … })
FocusChanged { focused: bool }.on_focus_changed(cx, |app, focused, cx| { … })
ItemFocused { item_id: SharedString }.on_item_focused(cx, |app, item_id, cx| { … })
ItemHoverChanged { item_id: SharedString, hovered: bool }.on_item_hover_changed(cx, |app, item_id, hovered, cx| { … })
EnabledChanged { enabled: bool }.on_enabled_changed(cx, |app, enabled, cx| { … })

Use .on_event(cx, |app, event, cx| { … }) for all events. Factory-created controls support the same callbacks through AccordionEventExt. Existing cx.subscribe observers remain supported.
