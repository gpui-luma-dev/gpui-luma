Color Swatch

Preview a retained source color, or use a swatch as an SDK button.

Preview and clickable swatch

Static preview and picker trigger
use std::sync::Arc;
use gpui::{Context, Entity, Render, Window, div, prelude::*, px};
use gpui_luma::color::ColorValue;
use gpui_luma::controls::button::Button;
use gpui_luma_color::{ColorSwatch, ColorSwatchButtonTemplate, ColorSwatchData};

struct Example {
    button: Entity<Button<ColorSwatchData>>,
    source: ColorValue,
    picker_requested: bool,
}
impl Example {
    fn new(cx: &mut Context<Self>) -> Self {
        let source = ColorValue::srgb(0.2, 0.5, 0.9, 0.65);
        let button = Button::new("accent-swatch")
            .typed(ColorSwatchData { color: source, checkerboard: true, ..Default::default() })
            .template(Arc::new(ColorSwatchButtonTemplate))
            .on_click(cx, |owner: &mut Self, cx| {
                owner.picker_requested = true;
                cx.notify();
            })
            .spawn(cx);
        Self { button, source, picker_requested: false }
    }
}
impl Render for Example {
    fn render(&mut self, _: &mut Window, _: &mut Context<Self>) -> impl IntoElement {
        div().flex().items_center().gap(px(8.0))
            .child(ColorSwatch::new(self.source).checkerboard(true).height(px(30.0)))
            .child(self.button.clone())
    }
}

Appearance and source colors

ColorSwatch is a renderable element; it has no events or spawned entity. Configure size(ControlSize), height, rounded, checkerboard, and bordered. Checkerboard is off by default on static swatches; enable it to reveal alpha.

Both swatch forms take ColorValue, retaining its source space and components. Previews use an sRGB fallback with CssLocalMinde mapping. Static swatches can select another policy with mapping. Invalid source colors render transparently; validate input with the strict source-color API when errors need to be reported.

Button events and updates

ColorSwatchButtonTemplate is a template for Button<ColorSwatchData>. The SDK Button handles click, focus, hover, and enabled events; no separate swatch event enum is needed. The example sets an application flag: it does not construct a picker automatically.

ClickNoneon_click
Open the application’s picker.
FocusChangedfocused: boolon_focus_changed
React to keyboard focus.
HoverChangedhovered: boolon_hover_changed

EnabledChangedenabled: boolon_enabled_changed
React to enablement changes.

Update the typed payload with button.update(cx, |button, cx| button.set_data(data, cx)) when the selected source color changes. Keep the source color in the owner model too, so previews and picker content share the same value. See picker composition and Button events.
