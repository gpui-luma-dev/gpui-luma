SDK/Color controls

Color Field

Select two color dimensions on a rectangle, triangle, or wheel.

Basic use

Saturation/value field with retained subscription
use gpui::{AppContext, Context, Entity, Render, Subscription, Window, prelude::*, px};
use gpui_luma_color::color_field::{ColorFieldEvent, ColorFieldState};
use gpui_luma_color::color_slider::color_spec::Hsv;

struct Example {
    field: Entity<ColorFieldState>,
    preview: Hsv,
    committed: Hsv,
    _events: Subscription,
}
impl Example {
    fn new(cx: &mut Context<Self>) -> Self {
        let hsv = Hsv { h: 210.0, s: 0.7, v: 0.8, a: 1.0 };
        let field = cx.new(|_| {
            ColorFieldState::saturation_value_rect("sv", hsv, 16.0)
                .vector().size(px(220.0)).rounded(px(12.0))
                .keyboard_steps(0.01, 0.1)
        });
        let events = cx.subscribe(&field, |owner: &mut Self, _, event, cx| {
            match event {
                ColorFieldEvent::Change(hsv) => owner.preview = *hsv,
                ColorFieldEvent::Release(hsv) => owner.committed = *hsv,
                _ => return,
            }
            cx.notify();
        });
        Self { field, preview: hsv, committed: hsv, _events: events }
    }
}
impl Render for Example {
    fn render(&mut self, _: &mut Window, _: &mut Context<Self>) -> impl IntoElement {
        self.field.clone()
    }
}

Planes and wheels

ConstructorInteraction
saturation_value_rectSaturation/value at fixed hue.
saturation_value_triangleSaturation/value within a triangle domain.
hue_saturation_wheelHue/saturation within a circle.
hue_saturationHue/saturation rectangle at fixed value.
hue_valueHue/value rectangle at fixed saturation.

Constructors return ColorFieldState; retain it with cx.new. Render the entity directly, or use ColorField::new(&state). Custom surfaces pair a FieldDomain2D with a ColorFieldModel2D through new, with_domain, and with_model.

Events and updates

Subscribe to ColorFieldEvent with cx.subscribe and match one variant per action. Retain the subscription, as in the example.

EventPayloadHandling
ChangeHsvUpdate the live preview.
ReleaseHsvCommit the final interaction value.
DragStarthsv: HsvBegin a pointer gesture.
DragEndhsv: HsvFinish a pointer gesture.
HoverChangedhovered: boolReact to pointer hover.
EnabledChangedenabled: boolReact to enablement changes.

Use set_hsv or set_hsv_components to synchronize another color editor into the field. The field is an HSV editing view, not storage for an original Display P3 or Oklch source.

Keyboard and rendering

An enabled field is one Tab stop and focuses on pointer press by default. Arrows move spatially by 1%; Shift+Arrow uses 10%. keyboard_steps, tab_stop, and pointer_focus_policy customize this. A changed keyboard adjustment emits Change and one final Release, without pointer drag events. Wheel input passes through.

vector() paints the field directly. Raster rendering is the default; raster_image_prewarmed(width, height) prepares its cache. inside_field, edge_to_edge, and edge_to_edge_clipped control thumb placement. Focus does not add a visual focus treatment; screen-reader semantics remain a follow-up in the current implementation.
