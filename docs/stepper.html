Stepper

look-shadcn

Show a process with discrete steps.

Basic use

SDK · integration snippet
use gpui_luma::controls::stepper;

let control = stepper::stepper("checkout", 4)
    .current_step(1)
    .spawn(cx);

Integration snippet, checked against the current SDK and Radix crates. cx is the initialized owner context. Keep spawned entities and subscriptions in the owning view.

SDK behavior & customization

Configure step count, current step, labels, and direction. It is a process indicator rather than Tabs.

Relevant contracts: StepperRenderModel, StepperTemplateModifier, StepperTemplate, ThemedStepperTemplate.

Use the module’s template contract for structural changes. Builder modifiers and item templates vary by control.

Application interaction

Stepper exposes no StepperEvent. The application advances its current step after validation or another command.
