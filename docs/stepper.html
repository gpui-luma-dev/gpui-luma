Advance and reset

Shadcn · Next and Reset
use gpui::{Context, Entity, Render, Window, div, prelude::*};
use gpui_luma::controls::{button::Button, stepper::Stepper};
use gpui_luma::infra::presenter::HasPresenter;
use gpui_luma_look_shadcn as shadcn;

struct Example {
    stepper: Stepper,
    next: Entity<Button>,
    reset: Entity<Button>,
}

impl Example {
    fn new(cx: &mut Context<Self>) -> Self {
        let stepper = shadcn::Stepper::new("setup", 3)
            .labels(vec!["Details", "Review", "Done"])
            .spawn(cx);
        let next = shadcn::Button::new("next").label("Next / Finish")
            .on_click(cx, |owner: &mut Self, cx| {
                owner.stepper.update(cx, |stepper, cx| {
                    let next = stepper.current_step() + 1;
                    if next < stepper.step_count() {
                        stepper.set_current_step(next, cx);
                    } else {
                        stepper.complete(cx);
                    }
                });
            })
            .spawn(cx);
        let reset = shadcn::Button::new("reset").label("Reset")
            .on_click(cx, |owner: &mut Self, cx| {
                owner.stepper.update(cx, |stepper, cx| stepper.set_current_step(0, cx));
            })
            .spawn(cx);
        Self { stepper, next, reset }
    }
}

impl Render for Example {
    fn render(&mut self, _: &mut Window, _: &mut Context<Self>) -> impl IntoElement {
        div().flex().flex_col().gap_3()
            .child(self.stepper.clone())
            .child(div().flex().gap_2().child(self.next.clone()).child(self.reset.clone()))
    }
}

Render this view in an initialized Luma application. Next advances through the three steps; another click completes the workflow. Reset returns to the first step.

SDK behavior & customization

Configure step count, current step, labels, and direction. It is a process indicator rather than Tabs.

Relevant contracts: StepperRenderModel, StepperTemplateModifier, StepperTemplate, ThemedStepperTemplate.

Use the module’s template contract for structural changes. Builder modifiers and item templates vary by control.

Application interaction

Stepper has no events of its own. Button’s on_click handlers drive it here. Indices start at zero; set_current_step derives each badge’s state, complete marks all steps complete, and setting a step again clears completion.
