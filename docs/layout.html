SDK/Layout

Layout

Arrange SDK controls with layout primitives and macros.

Stacks & wrapping

vstack! arranges children vertically, hstack! horizontally, and wrappanel! wraps children onto additional lines. They return GPUI flex elements; they do not spawn control entities or need a Look.

Use gap for spacing, align for cross-axis alignment, and stack justify options for main-axis distribution. Import GPUI’s prelude for the element methods used by these macros. flow! is a legacy compatibility alias; prefer wrappanel! for new code.

Dock, grid & layers

DockPanel / dock_panel! place children against edges, with the last child filling the remainder by default. GridLayout / grid_layout! use fixed-pixel or proportional column tracks and support column spans. Both builders expose .build().

LayerStack paints later layers above earlier layers and applies a shared corner radius to the layer roots. It does not clip arbitrary descendant backgrounds to rounded corners.

Rust
use gpui::{div, prelude::*, px};
use gpui_luma::{hstack, vstack, wrappanel, dock_panel, grid_layout};
use gpui_luma::{GridTrack, LayerStack};

fn stacks() -> impl IntoElement {
    vstack! { gap=12 align=start;
        hstack! { gap=8 align=center; div().child("Name"), div().child("Value") },
        wrappanel! { gap=8; div().child("One"), div().child("Two") },
    }
}

fn docked() -> impl IntoElement {
    dock_panel! {
        top: div().child("Header"),
        left: div().w(px(180.0)).child("Sidebar"),
        fill: div().child("Content"),
    }.build()
}

fn grid() -> impl IntoElement {
    grid_layout! {
        rows: 1, columns: [GridTrack::Px(180.0), GridTrack::Star(1.0)], gap: 12;
        [0, 0] => div().child("Label"),
        [0, 1] => div().child("Content"),
    }.build()
}

fn layers() -> impl IntoElement {
    LayerStack::new(px(8.0))
        .layer(div().child("Background layer"))
        .layer(div().child("Foreground layer"))
}

Wide Middle

WideMiddle and WideMiddleLayout provide a responsive three-region layout. At narrow widths, the middle moves below the leading and trailing regions. Retain the host returned by spawn_wide_middle, then compose its regions with WideMiddleLayout::new(...).build(cx). Configure side widths, middle bounds, and gap on the host.

Containers

  • Frame: arrange and optionally decorate a container.
  • Scroll Container: host scrollable content and scrollbar chrome.

For draggable layout behavior, use the controls Dock Splitter, Resizable Panels, and Split View.
