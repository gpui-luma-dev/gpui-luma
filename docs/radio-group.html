Radio Group

A group with one selected option.

Basic use

Radix · integration snippet
use gpui::{Context};
use gpui_luma_look_radix as radix;
use gpui_luma::controls::control_group::ControlGroupItem;

struct Example {
    control: gpui_luma::controls::radio_group::RadioGroup<gpui_luma::controls::control_group::ControlGroupItem>,
    density: Option<gpui::SharedString>,
}

impl Example {
    fn new(cx: &mut Context<Self>) -> Self {
        let control = radix::RadioGroup::new("example")
            .items([
                ControlGroupItem::new("compact").label("Compact"),
                ControlGroupItem::new("comfortable").label("Comfortable"),
            ])
            .selected("comfortable")
            .on_value_changed(cx, |app, value, cx| {
                app.density = value.clone();
                cx.notify();
            })
            .spawn(cx);

        Self { control, density: Some("comfortable".into()) }
    }
}

Integration snippet, checked against the current SDK and Radix crates. cx is the initialized owner context. The control retains its callbacks; callback owners are held weakly. Render self.control.clone() in the owner’s view.

SDK behavior & customization

Group selection and navigation reuse Control Group. Change carries the selected ID.

Relevant contracts: RadioGroupRenderModel, RadioGroupTemplate, RadioGroupTemplateHandlers.

Use the module’s template contract for structural changes. Builder modifiers and item templates vary by control.

Events

Callbacks follow the existing SDK event stream. Registrations append, hold the owner weakly, and live until the control is released. cx.notify() requests an owner redraw. Compound payloads are borrowed; scalar values are passed by value.

Event / payloadCallback
Change { value: Option<SharedString> }.on_value_changed(cx, |app, value, cx| { … })
Activate { value: SharedString }.on_activate(cx, |app, value, cx| { … })
FocusChanged { focused: bool }.on_focus_changed(cx, |app, focused, cx| { … })
ItemFocused { item_id: SharedString }.on_item_focused(cx, |app, item_id, cx| { … })

Use .on_event(cx, |app, event, cx| { … }) for all events. Factory-created controls support the same callbacks through RadioGroupEventExt. Existing cx.subscribe observers remain supported.
