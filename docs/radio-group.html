Radio Group

A group with one selected option.

Basic use

Radix · integration snippet
use gpui::{Context, Subscription};
use gpui_luma::controls::radio_group::RadioGroupEvent;
use gpui_luma_look_radix as radix;
use gpui_luma::controls::control_group::ControlGroupItem;

struct Example {
    control: gpui_luma::controls::radio_group::RadioGroup<gpui_luma::controls::control_group::ControlGroupItem>,
    density: Option<gpui::SharedString>,
    _subscription: Subscription,
}

impl Example {
    fn new(cx: &mut Context<Self>) -> Self {
        let control = radix::RadioGroup::new("example")
            .items([
                ControlGroupItem::new("compact").label("Compact"),
                ControlGroupItem::new("comfortable").label("Comfortable"),
            ])
            .selected("comfortable")
            .spawn(cx);

        let subscription = cx.subscribe(&control, |app, _, event: &RadioGroupEvent, cx| {
            if let RadioGroupEvent::Change { value } = event {
                app.density = value.clone();
                cx.notify();
            }
        });

        Self { control, density: Some("comfortable".into()), _subscription: subscription }
    }
}

Integration snippet, checked against the current SDK and Radix crates. cx is the initialized owner context. The example retains both the control and its subscription. Render self.control.clone() in the owner’s view.

SDK behavior & customization

Group selection and navigation reuse Control Group. Change carries the selected ID.

Relevant contracts: RadioGroupRenderModel, RadioGroupTemplate, RadioGroupTemplateHandlers.

Use the module’s template contract for structural changes. Builder modifiers and item templates vary by control.

Events

The callback updates application state. Retain the subscription for as long as the owner needs events; dropping it unsubscribes. cx.notify() requests an owner redraw.

Event / payloadApplication use
Change { value: Option<SharedString> }Update the selected option ID.
Activate { value: SharedString }An item was activated; handle its application action.
FocusChanged { focused: bool }Focus state changed.
ItemFocused { item_id: SharedString }An item received focus.

RadioGroupEvent · Event definitions. Match the events you need; allow for other variants.

Look differences

Radix provides an adapter for this SDK role. Variant names, sizes, and styling options belong to the Look, not the SDK contract. Builders use ambient Look resolution unless you explicitly override it.
