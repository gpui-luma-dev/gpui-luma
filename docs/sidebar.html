SDK/Controls

Sidebar

Grouped application navigation.

Basic use

SDK · integration snippet
use gpui::{Context, Subscription};
use gpui_luma::controls::sidebar::SidebarEvent;
use gpui_luma::controls::sidebar;

struct Example {
    control: gpui::Entity<gpui_luma::controls::sidebar::SidebarControl>,
    active_destination: String,
    _subscription: Subscription,
}

impl Example {
    fn new(cx: &mut Context<Self>) -> Self {
        let control = sidebar::new("navigation").spawn(cx);
        // Compose header, menus, and footer through the sidebar builder.

        let subscription = cx.subscribe(&control, |app, _, event: &SidebarEvent, cx| {
            if let SidebarEvent::Select { id } = event {
                app.active_destination = id.to_string();
                cx.notify();
            }
        });

        Self { control, active_destination: String::new(), _subscription: subscription }
    }
}

Integration snippet, checked against the current SDK and Radix crates. cx is the initialized owner context. The example retains both the control and its subscription. Render self.control.clone() in the owner’s view.

SDK behavior & customization

The control owns navigation presentation. The host owns pane width and visibility.

Use the module’s template contract for structural changes. Builder modifiers and item templates vary by control.

Events

The callback updates application state. Retain the subscription for as long as the owner needs events; dropping it unsubscribes. cx.notify() requests an owner redraw.

Event / payloadApplication use
PresentationChanged { presentation: SidebarPresentation }Sidebar presentation changed; host pane visibility remains separate.
Select { id: SharedString }An option or command was selected; use its stable ID.
ItemFocused { id: SharedString }An item received focus.
HoverChanged { id: Option<SharedString> }Pointer hover state changed.
SubMenuToggle { id: SharedString, open: bool }A sidebar branch changed expansion state.
EnabledChanged { enabled: bool }Enabled state changed.

SidebarEvent · Event definitions. Match the events you need; allow for other variants.

Look differences

No dedicated Radix factory is exported for this SDK module. Use the SDK contract shown here; integrate a custom template or theme where the module supports one. Do not assume Shadcn and Radix have matching factories.
