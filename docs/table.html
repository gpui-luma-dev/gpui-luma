SDK/Controls

Table

Records in rows and columns.

Basic use

SDK · integration snippet
use gpui::{Context};
use gpui_luma::controls::table::{self, TableSelectionMode};

struct Example {
    control: gpui::Entity<gpui_luma::controls::table::TableControl<String>>,
    selected_rows: Vec<usize>,
}

impl Example {
    fn new(cx: &mut Context<Self>) -> Self {
        let control = table::new_typed::<String>("records")
            .items(["Draft".to_string(), "Published".to_string()])
            .row_label(|row| row.clone())
            .selection_mode(TableSelectionMode::Single)
            .on_selection_changed(cx, |app, selected_indices, cx| {
                app.selected_rows = selected_indices.clone();
                cx.notify();
            })
            .spawn(cx);

        Self { control, selected_rows: Vec::new() }
    }
}

Integration snippet, checked against the current SDK and Radix crates. cx is the initialized owner context. The control retains its callbacks; callback owners are held weakly. Render self.control.clone() in the owner’s view.

SDK behavior & customization

SDK selection supports Single, Multiple, Extended, and None. Stable row keys matter for reordering and selection.

Relevant contracts: TableColumnRenderModel, TableRenderModel, TableHeaderTemplate, TableRowRenderModel.

Use the module’s template contract for structural changes. Builder modifiers and item templates vary by control.

Events

Callbacks follow the existing SDK event stream. Registrations append, hold the owner weakly, and live until the control is released. cx.notify() requests an owner redraw. Compound payloads are borrowed; scalar values are passed by value.

Event / payloadCallback
RowDrag(TableRowDragEvent).on_row_drag(cx, |app, event, cx| { … })
SelectionChanged { selected_indices: Vec<usize> }.on_selection_changed(cx, |app, selected_indices, cx| { … })
SelectedKeysChanged { selected_keys: Vec<SharedString> }.on_selected_keys_changed(cx, |app, selected_keys, cx| { … })
ActiveIndexChanged { active_index: Option<usize> }.on_active_index_changed(cx, |app, active_index, cx| { … })
PageChanged { page: usize }.on_page_changed(cx, |app, page, cx| { … })
PageSizeChanged { page_size: usize }.on_page_size_changed(cx, |app, page_size, cx| { … })
ScrollChanged { top_index: usize }.on_scroll_changed(cx, |app, top_index, cx| { … })
FocusChanged { focused: bool }.on_focus_changed(cx, |app, focused, cx| { … })
RowHoverChanged { index: usize, hovered: bool }.on_row_hover_changed(cx, |app, index, hovered, cx| { … })
EnabledChanged { enabled: bool }.on_enabled_changed(cx, |app, enabled, cx| { … })

Use .on_event(cx, |app, event, cx| { … }) for all events. Factory-created controls support the same callbacks through TableEventExt. Existing cx.subscribe observers remain supported.
