SDK/Controls

Slider

Choose a value on a track.

Basic use

Radix · integration snippet
use gpui::{Context, Subscription};
use gpui_luma::controls::slider::SliderEvent;
use gpui_luma_look_radix as radix;

struct Example {
    control: gpui_luma::controls::slider::Slider,
    preview: f32,
    committed: f32,
    _subscription: Subscription,
}

impl Example {
    fn new(cx: &mut Context<Self>) -> Self {
        let control = radix::Slider::new("example").range(0..100).value(25.0).spawn(cx);

        let subscription = cx.subscribe(&control, |app, _, event: &SliderEvent, cx| {
            match event {
                SliderEvent::Change { value, .. } => {
                    app.preview = *value;
                }
                SliderEvent::Release { value, .. } => {
                    app.committed = *value;
                }
                _ => return,
            }
            cx.notify();
        });

        Self { control, preview: 25.0, committed: 25.0, _subscription: subscription }
    }
}

Integration snippet, checked against the current SDK and Radix crates. cx is the initialized owner context. The example retains both the control and its subscription. Render self.control.clone() in the owner’s view.

SDK behavior & customization

Use Change for live updates and Release for committed interaction values. Thumb IDs identify the changed thumb.

Relevant contracts: SliderRenderModel.

Use the module’s template contract for structural changes. Builder modifiers and item templates vary by control.

Events

The callback updates application state. Retain the subscription for as long as the owner needs events; dropping it unsubscribes. cx.notify() requests an owner redraw.

Event / payloadApplication use
Change { thumb_id: ThumbId, value: f32 }Update live preview; use Release for commit.
Release { thumb_id: ThumbId, value: f32 }Commit the interaction value.
DragStart { thumb_id: ThumbId }Dragging began.
DragEnd { thumb_id: ThumbId, value: f32 }Dragging ended; includes the final value where provided.
ThumbAdded { thumb_id: ThumbId, value: f32 }A slider thumb was added.
ThumbRemoved { thumb_id: ThumbId }A slider thumb was removed.
ThumbSelected { thumb_id: ThumbId }The active slider thumb changed.
FocusChanged { focused: bool }Focus state changed.
HoverChanged { hovered: bool }Pointer hover state changed.

Look differences

Radix provides an adapter for this SDK role. Variant names, sizes, and styling options belong to the Look, not the SDK contract. Builders use ambient Look resolution unless you explicitly override it.

Radix variants: Classic, Surface, Soft.
