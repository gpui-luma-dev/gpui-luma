Why a Look?

Share control behavior. Choose the visual design.

Why?

Button activation, focus, and events belong in the SDK. Colors, metrics, typography, and visual structure can vary by Look.

How?

Builders resolve the application’s global Look automatically, falling back to built-in styling. Explicit .look(&custom_look) is an optional override.

A Look builder configures an SDK template and creates an SDK control. Application code keeps the entity and handles its events.

Look → SDK
use gpui_luma::infra::presenter::HasPresenter;
use gpui_luma_look_shadcn as shadcn;

let button = shadcn::Button::new("save")
    .primary().label("Save")
    .on_click(cx, |app, cx| { app.save_requests += 1; cx.notify(); })
    .spawn(cx);

Integration snippet: an initialized owner context with a save_requests: usize field are required.
