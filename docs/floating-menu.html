Floating Menu

Shared menu rendering infrastructure.

Basic use

SDK · integration snippet
use gpui_luma::controls::floating_menu::FloatingMenuState;

let mut state = FloatingMenuState::default();
state.open_with(None);
// PopupMenu and ContextMenu normally manage this state for you.

Integration snippet, checked against the current SDK and Radix crates. cx is the initialized owner context. Keep spawned entities and subscriptions in the owning view.

SDK behavior & customization

Not a spawnable control. Popup Menu and Context Menu use it for highlight state and submenu chrome.

Relevant contracts: FloatingMenuRenderModel, FloatingMenuTemplateHandlers, FloatingMenuTemplateModifier, FloatingMenuTemplate.

Use the module’s template contract for structural changes. Builder modifiers and item templates vary by control.

Application interaction

Floating Menu is rendering infrastructure. Subscribe to PopupMenuEvent or ContextMenuEvent on the owning control.
