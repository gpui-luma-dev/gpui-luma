Frame

look-shadcn

Decorate and arrange a container.

Basic use

SDK · integration snippet
use gpui::{div, prelude::*, px};
use gpui_luma::controls::frame::FrameBuilder;

let control = FrameBuilder::new("inspector")
    .flex().flex_col().gap(px(8.0))
    .child_render(|| div().child("Inspector"))
    .spawn(cx);

Integration snippet, checked against the current SDK and Radix crates. cx is the initialized owner context. Keep spawned entities and subscriptions in the owning view.

SDK behavior & customization

Frame has no focus, selection, scrolling, or pane visibility state. Explicit GPUI styling overrides look defaults.

Application interaction

Frame exposes no FrameEvent. Subscribe to its child controls for user actions; the frame supplies decoration and layout.
