Progress

Show progress through a numeric range.

Basic use

Radix · integration snippet
use gpui_luma_look_radix as radix;

let control = radix::Progress::new("example")
    .range(0..100)
    .value(40.0)
    .spawn(cx);

Integration snippet, checked against the current SDK and Radix crates. cx is the initialized owner context. Keep spawned entities and subscriptions in the owning view.

SDK behavior & customization

A read-only indicator. Update its value from application state; it is not a value picker.

Relevant contracts: ProgressRenderModel.

Use the module’s template contract for structural changes. Builder modifiers and item templates vary by control.

Application interaction

Progress is read-only and exposes no ProgressEvent. Update its value from application work; subscribe to the interactive control that starts or cancels that work.
