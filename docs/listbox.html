SDK/Controls

List Box

A keyed, selectable flat collection.

Basic use

Radix · integration snippet
use gpui::{Context, Render, Window, div, prelude::*};
use gpui_luma::controls::listbox::{
    ListBoxControl, ListBoxEvent, ListBoxInput, ListBoxState, ListBoxError, SelectionMode, make_listbox_item_template,
};
use gpui_luma_look_radix as radix;

struct Example {
    list: ListBoxControl<Self, String, String>,
    selected: Vec<String>,
    last_opened: Option<String>,
}

impl Example {
    fn try_new(cx: &mut Context<Self>) -> Result<Self, ListBoxError> {
        let state = ListBoxState::try_new(
            ["Draft".to_string(), "Published".to_string()],
            |row| row.clone(),
            SelectionMode::SingleRequired,
        )?;
        let list = ListBoxControl::new(state, Self::on_input, |key| key.clone().into(), |row| row.clone().into(), cx);
        Ok(Self { list, selected: Vec::new(), last_opened: None })
    }

    fn on_input(&mut self, input: ListBoxInput<String>, _: &mut Window, cx: &mut Context<Self>) {
        let update = self.list.apply(input, cx);
        for event in update.events {
            match event {
                ListBoxEvent::SelectionChanged { selected, .. } => self.selected = selected,
                ListBoxEvent::ItemActivated { key } => self.last_opened = Some(key),
                _ => {}
            }
        }
        cx.notify();
    }
}

impl Render for Example {
    fn render(&mut self, window: &mut Window, cx: &mut Context<Self>) -> impl IntoElement {
        let template = make_listbox_item_template(
            |model: &gpui_luma::controls::listbox::ListBoxItemRenderModel<'_, String>, _| {
                div().child(model.item.clone())
            },
        );
        radix::ListBoxBuilder::new("items", &mut self.list, template).build(window, cx)
    }
}

SDK behavior & customization

Keep ListBoxControl state persistent. Hosts compose content, viewport, and event delivery.

Relevant contracts: ListBoxItemRenderModel, ListBoxItemTemplate.

Use the module’s template contract for structural changes. Builder modifiers and item templates vary by control.

Events

List Box is host-owned, not a separately spawned event emitter. Its input callback applies SDK input, delivers the returned events to application state, and requests a redraw.

Event / payloadApplication use
SelectionPolicyChanged { policy: SelectionPolicy }Selection policy changed.
SelectionChanged { selected: Vec<K>, active: Option<K> }Selection changed; use the supplied indices, IDs, or keys.
ActiveItemChanged { active: Option<K> }The active item changed independently of selection.
ItemActivated { key: K }An item was activated; open or execute its application action.
ProjectionChanged { visible_count: usize }The visible projection changed.
FocusChanged { is_focused: bool }Focus state changed.

ListBoxEvent · Event definitions. Match the events you need; allow for other variants.

Look differences

Radix provides an adapter for this SDK role. Variant names, sizes, and styling options belong to the Look, not the SDK contract. Builders use ambient Look resolution unless you explicitly override it.
