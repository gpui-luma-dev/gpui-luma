Luma/Text Field

Text Field

A native editable field with look-specific styling.

This page describes the SDK control. Code uses the Radix Look; builders use the ambient Look or built-in fallback.

Create it

Radix · integration snippet
use gpui::{Context, Subscription};
use gpui_luma::controls::textfield::TextFieldEvent;
use gpui_luma_look_radix as radix;

struct Example {
    control: gpui_luma::controls::textfield::TextField,
    name: String,
    _subscription: Subscription,
}

impl Example {
    fn new(cx: &mut Context<Self>) -> Self {
        let control = radix::TextField::new("name").spawn(cx);

        let subscription = cx.subscribe(&control, |app, _, event: &TextFieldEvent, cx| {
            if let TextFieldEvent::Change { value } = event {
                app.name = value.clone();
                cx.notify();
            }
        });

        Self { control, name: String::new(), _subscription: subscription }
    }
}

Checked against the current SDK and Radix crates. The owner retains the control and subscription. Render self.control.clone() in its view.

Customize & handle input

Inspect the builder for value, validation, and event options. Text fields have a dedicated template contract; do not copy Button template assumptions.

Events

The callback updates application state. Retain the subscription for as long as the owner needs events; dropping it unsubscribes. cx.notify() requests an owner redraw.

Event / payloadApplication use
Change { value: String }Update application text or validation state.
Submit { value: String }The field submitted its current value.
FocusChanged { focused: bool }Focus state changed.
EnabledChanged { enabled: bool }Enabled state changed.

TextFieldEvent · Event definitions. Match the events you need; allow for other variants.

Look differences

Radix provides Classic, Surface, and Soft variants. Variant names, sizes, and customization options belong to each Look; they are not SDK requirements.

Use the chosen Look’s builder for appearance. Keep application logic tied to SDK state and events.
