ComboBox

look-shadcn

An editable query with selectable options.

Basic use

SDK · integration snippet
use gpui::{Context};
use gpui_luma::controls::combobox::{self, SelectionItem};

struct Example {
    control: gpui_luma::controls::combobox::ComboBox,
    query: String,
}

impl Example {
    fn new(cx: &mut Context<Self>) -> Self {
        let control = combobox::new("search", [SelectionItem::new("rust", "Rust")]).on_value_changed(cx, |app, query, cx| {
                app.query = query.to_string();
                cx.notify();
            })
            .spawn(cx);



        Self { control, query: String::new() }
    }
}

Integration snippet, checked against the current SDK and Radix crates. cx is the initialized owner context. The control retains its callbacks; callback owners are held weakly. Render self.control.clone() in the owner’s view.

SDK behavior & customization

Control, panel, and item templates are separate extension points. Prefer panel_template and with_item_template for new customization.

Relevant contracts: ComboBoxItemRenderModel, ComboBoxItemTemplate, ComboBoxItemTemplateModifier, ComboBoxItemsRenderModel.

Use the module’s template contract for structural changes. Builder modifiers and item templates vary by control.

Events

Callbacks follow the existing SDK event stream. Registrations append, hold the owner weakly, and live until the control is released. cx.notify() requests an owner redraw. Compound payloads are borrowed; scalar values are passed by value.

Event / payloadCallback
Change { query: SharedString }.on_value_changed(cx, |app, query, cx| { … })
Select { item_id: SharedString, label: SharedString }.on_select(cx, |app, item_id, label, cx| { … })
Complete { item_id: SharedString, label: SharedString }.on_complete(cx, |app, item_id, label, cx| { … })
Clear.on_clear(cx, |app, cx| { … })
FocusChanged { focused: bool }.on_focus_changed(cx, |app, focused, cx| { … })
OpenChanged { open: bool }.on_open_changed(cx, |app, open, cx| { … })
Dismiss.on_dismiss(cx, |app, cx| { … })

Use .on_event(cx, |app, event, cx| { … }) for all events. Factory-created controls support the same callbacks through ComboBoxEventExt. Existing cx.subscribe observers remain supported.
