SDK/Controls

ComboBox

An editable query with selectable options.

Basic use

SDK · integration snippet
use gpui::{Context, Subscription};
use gpui_luma::controls::combobox::ComboBoxEvent;
use gpui_luma::controls::combobox::{self, SelectionItem};

struct Example {
    control: gpui_luma::controls::combobox::ComboBox,
    query: String,
    _subscription: Subscription,
}

impl Example {
    fn new(cx: &mut Context<Self>) -> Self {
        let control = combobox::new("search", [SelectionItem::new("rust", "Rust")]).spawn(cx);

        let subscription = cx.subscribe(&control, |app, _, event: &ComboBoxEvent, cx| {
            if let ComboBoxEvent::Change { query } = event {
                app.query = query.to_string();
                cx.notify();
            }
        });

        Self { control, query: String::new(), _subscription: subscription }
    }
}

Integration snippet, checked against the current SDK and Radix crates. cx is the initialized owner context. The example retains both the control and its subscription. Render self.control.clone() in the owner’s view.

SDK behavior & customization

Control, panel, and item templates are separate extension points. Prefer panel_template and with_item_template for new customization.

Relevant contracts: ComboBoxItemRenderModel, ComboBoxItemTemplate, ComboBoxItemTemplateModifier, ComboBoxItemsRenderModel.

Use the module’s template contract for structural changes. Builder modifiers and item templates vary by control.

Events

The callback updates application state. Retain the subscription for as long as the owner needs events; dropping it unsubscribes. cx.notify() requests an owner redraw.

Event / payloadApplication use
Change { query: SharedString }The query changed; update filtering or suggestions in the application.
Select { item_id: SharedString, label: SharedString }An option or command was selected; use its stable ID.
Complete { item_id: SharedString, label: SharedString }An option was completed into the text input.
ClearThe query/selection clear action occurred.
FocusChanged { focused: bool }Focus state changed.
OpenChanged { open: bool }Popup visibility changed.
DismissThe popup was dismissed.

ComboBoxEvent · Event definitions. Match the events you need; allow for other variants.

Look differences

No dedicated Radix factory is exported for this SDK module. Use the SDK contract shown here; integrate a custom template or theme where the module supports one. Do not assume Shadcn and Radix have matching factories.
