Tree View

A hierarchical collection.

Basic use

Radix · integration snippet
use gpui::{Context, Subscription};
use gpui_luma::controls::tree_view::TreeViewEvent;
use gpui_luma_look_radix as radix;
use gpui_luma::controls::tree_view::TreeNode;

struct Example {
    control: gpui_luma::controls::tree_view::TreeView<()>,
    selected_nodes: std::collections::HashSet<gpui::SharedString>,
    _subscription: Subscription,
}

impl Example {
    fn new(cx: &mut Context<Self>) -> Self {
        let control = radix::TreeView::<()>::new("example").items([TreeNode::new("root", "Workspace", ())]).spawn(cx);

        let subscription = cx.subscribe(&control, |app, _, event: &TreeViewEvent<()>, cx| {
            if let TreeViewEvent::SelectionChanged { selected_ids } = event {
                app.selected_nodes = selected_ids.clone();
                cx.notify();
            }
        });

        Self { control, selected_nodes: Default::default(), _subscription: subscription }
    }
}

Integration snippet, checked against the current SDK and Radix crates. cx is the initialized owner context. The example retains both the control and its subscription. Render self.control.clone() in the owner’s view.

SDK behavior & customization

Rows own disclosure, selection, focus, and scrolling. Use Frame for optional outer decoration.

Relevant contracts: TreeViewRenderModel, TreeViewTemplateHandlers, TreeViewTemplateModifier, TreeViewTemplate.

Use the module’s template contract for structural changes. Builder modifiers and item templates vary by control.

Events

The callback updates application state. Retain the subscription for as long as the owner needs events; dropping it unsubscribes. cx.notify() requests an owner redraw.

Look differences

Radix provides an adapter for this SDK role. Variant names, sizes, and styling options belong to the Look, not the SDK contract. Builders use ambient Look resolution unless you explicitly override it.
