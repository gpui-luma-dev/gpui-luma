Control Group

look-shadcn

Compose controls with coordinated selection and focus.

Basic use

SDK · integration snippet
use gpui::{Context};
use gpui_luma::controls::control_group::{self, ControlGroupItem};

struct Example {
    control: gpui_luma::controls::control_group::ControlGroup<gpui_luma::controls::control_group::ControlGroupItem>,
    selected_tools: Vec<gpui::SharedString>,
}

impl Example {
    fn new(cx: &mut Context<Self>) -> Self {
        let control = control_group::new::<ControlGroupItem>("actions")
            .items([ControlGroupItem::new("open").label("Open")])
            .on_value_changed(cx, |app, _, _, selected_ids, cx| {
                app.selected_tools = selected_ids.clone();
                cx.notify();
            })
            .spawn(cx);

        Self { control, selected_tools: Vec::new() }
    }
}

Integration snippet, checked against the current SDK and Radix crates. cx is the initialized owner context. The control retains its callbacks; callback owners are held weakly. Render self.control.clone() in the owner’s view.

SDK behavior & customization

The shared group engine supports custom item and container templates.

Relevant contracts: ControlGroupItemRenderModel, ControlGroupRenderModel, ControlGroupTemplateHandlers, ControlGroupItemTemplate.

Use the module’s template contract for structural changes. Builder modifiers and item templates vary by control.

Events

Callbacks follow the existing SDK event stream. Registrations append, hold the owner weakly, and live until the control is released. cx.notify() requests an owner redraw. Compound payloads are borrowed; scalar values are passed by value.

Event / payloadCallback
Activate { activated_id: SharedString }.on_activate(cx, |app, activated_id, cx| { … })
Change { changed_id: SharedString, selected: bool, selected_ids: Vec<SharedString> }.on_value_changed(cx, |app, changed_id, selected, selected_ids, cx| { … })
ItemBoundsChanged { item_id: SharedString, bounds: Bounds<Pixels> }.on_item_bounds_changed(cx, |app, item_id, bounds, cx| { … })
FocusChanged { focused: bool }.on_focus_changed(cx, |app, focused, cx| { … })
ItemFocused { item_id: SharedString }.on_item_focused(cx, |app, item_id, cx| { … })

Use .on_event(cx, |app, event, cx| { … }) for all events. Factory-created controls support the same callbacks through ControlGroupEventExt. Existing cx.subscribe observers remain supported.
