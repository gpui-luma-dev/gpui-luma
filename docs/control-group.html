SDK/Controls

Control Group

Compose controls with coordinated selection and focus.

Basic use

SDK · integration snippet
use gpui::{Context, Subscription};
use gpui_luma::controls::control_group::ControlGroupEvent;
use gpui_luma::controls::control_group::{self, ControlGroupItem};

struct Example {
    control: gpui_luma::controls::control_group::ControlGroup<gpui_luma::controls::control_group::ControlGroupItem>,
    selected_tools: Vec<gpui::SharedString>,
    _subscription: Subscription,
}

impl Example {
    fn new(cx: &mut Context<Self>) -> Self {
        let control = control_group::new::<ControlGroupItem>("actions")
            .items([ControlGroupItem::new("open").label("Open")])
            .spawn(cx);

        let subscription = cx.subscribe(&control, |app, _, event: &ControlGroupEvent, cx| {
            if let ControlGroupEvent::Change { selected_ids, .. } = event {
                app.selected_tools = selected_ids.clone();
                cx.notify();
            }
        });

        Self { control, selected_tools: Vec::new(), _subscription: subscription }
    }
}

Integration snippet, checked against the current SDK and Radix crates. cx is the initialized owner context. The example retains both the control and its subscription. Render self.control.clone() in the owner’s view.

SDK behavior & customization

The shared group engine supports custom item and container templates.

Relevant contracts: ControlGroupItemRenderModel, ControlGroupRenderModel, ControlGroupTemplateHandlers, ControlGroupItemTemplate.

Use the module’s template contract for structural changes. Builder modifiers and item templates vary by control.

Events

The callback updates application state. Retain the subscription for as long as the owner needs events; dropping it unsubscribes. cx.notify() requests an owner redraw.

Event / payloadApplication use
Activate { activated_id: SharedString }An item was activated; handle its application action.
Change { changed_id: SharedString, selected: bool, selected_ids: Vec<SharedString> }Group selection changed.
ItemBoundsChanged { item_id: SharedString, bounds: Bounds<Pixels> }An item’s bounds changed.
FocusChanged { focused: bool }Focus state changed.
ItemFocused { item_id: SharedString }An item received focus.

ControlGroupEvent · Event definitions. Match the events you need; allow for other variants.

Look differences

No dedicated Radix factory is exported for this SDK module. Use the SDK contract shown here; integrate a custom template or theme where the module supports one. Do not assume Shadcn and Radix have matching factories.
