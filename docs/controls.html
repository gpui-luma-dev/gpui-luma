SDK/Controls

Controls

SDK contracts. Radix examples where an adapter exists.

Button

  • ButtonExecute an action.
  • Icon ButtonAn icon-only command button.
  • Split ButtonAn action face with an adjacent menu trigger.

Choice

  • CheckboxA boolean choice.
  • Radio ButtonOne option in a mutually exclusive choice.
  • Radio GroupA group with one selected option.
  • SwitchAn on/off setting.
  • ToggleA command with persistent selection.
  • ToolbarA row of commands and embedded controls.
  • Control GroupCompose controls with coordinated selection and focus.
  • Icon GroupAn icon toolbar preset.

Text

  • Text FieldSingle-line editable text.
  • Text AreaMultiline editable text.

Range

  • SliderChoose a value on a track.
  • ProgressShow progress through a numeric range.

Collection

  • List BoxA keyed, selectable flat collection.
  • TableRecords in rows and columns.
  • Tree ViewA hierarchical collection.

Selection

  • SelectorA trigger that opens an option list.
  • ComboBoxAn editable query with selectable options.
  • AutocompleteSuggest options while entering a query.
  • Search SelectorSearch and choose an option.
  • Selection PanelAn always-visible option list.
  • Selector ListShared option-list rendering infrastructure.

Navigation

  • AccordionExpandable sections.
  • TabsSwitch between sections or destinations.
  • SidebarGrouped application navigation.
  • PagerNavigate pages of records.
  • StepperShow a process with discrete steps.

Overlay

  • Popup MenuOpen a command menu from a trigger.
  • Context MenuCommands attached to a target surface.
  • Popover ButtonA trigger-owned popup surface.
  • Overlay WindowA modal or modeless overlay.
  • TooltipNoninteractive help attached to a control.
  • Slide PanelAn edge-anchored drawer.
  • Floating MenuShared menu rendering infrastructure.

Layout

  • FrameDecorate and arrange a container.
  • Dock SplitterA draggable boundary between dock regions.
  • Resizable PanelsPanels separated by draggable handles.
  • Split ViewA resizable sidebar and content region.
  • Scroll ContainerA viewport with scrollbar hosting.
  • ScrollbarAn interactive scroll position control.
  • Popup Scroll SurfaceScroll hosting for popup content.
