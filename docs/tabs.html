Switch between sections or destinations.

Basic use

Radix · integration snippet
use gpui::{Context};
use gpui_luma::controls::tabs::TabsItem;
use gpui_luma_look_radix as radix;

struct Example {
    control: gpui::Entity<gpui_luma::controls::tabs::Tabs>,
    active_tab: String,
}

impl Example {
    fn new(cx: &mut Context<Self>) -> Self {
        let control = radix::Tabs::new("settings")
            .items([TabsItem::new("account").label("Account"), TabsItem::new("appearance").label("Appearance")])
            .active("account")
            .on_value_changed(cx, |app, tab_id, _, cx| {
                app.active_tab = tab_id.to_string();
                cx.notify();
            })
            .spawn(cx);

        Self { control, active_tab: "account".into() }
    }
}

Integration snippet, checked against the current SDK and Radix crates. cx is the initialized owner context. The control retains its callbacks; callback owners are held weakly. Render self.control.clone() in the owner’s view.

SDK behavior & customization

Supports navigation-only items and retained panels. Choose panel retention and animation intentionally.

Relevant contracts: TabsRenderModel, TabsTemplateHandlers, TabsTemplateModifier, TabsTemplate.

Use the module’s template contract for structural changes. Builder modifiers and item templates vary by control.

Events

Callbacks follow the existing SDK event stream. Registrations append, hold the owner weakly, and live until the control is released. cx.notify() requests an owner redraw. Compound payloads are borrowed; scalar values are passed by value.

Event / payloadCallback
Change { tab_id: SharedString, label: SharedString }.on_value_changed(cx, |app, tab_id, label, cx| { … })
Activate { tab_id: SharedString, label: SharedString }.on_activate(cx, |app, tab_id, label, cx| { … })
Reactivate { tab_id: SharedString, label: SharedString }.on_reactivate(cx, |app, tab_id, label, cx| { … })
DropdownRequested { tab_id: SharedString, label: SharedString, bounds: Option<Bounds<Pixels>> }.on_dropdown_requested(cx, |app, tab_id, label, bounds, cx| { … })
ItemBoundsChanged { tab_id: SharedString, bounds: Bounds<Pixels> }.on_item_bounds_changed(cx, |app, tab_id, bounds, cx| { … })
FocusChanged { focused: bool }.on_focus_changed(cx, |app, focused, cx| { … })
ItemFocused { tab_id: SharedString, label: SharedString }.on_item_focused(cx, |app, tab_id, label, cx| { … })

Use .on_event(cx, |app, event, cx| { … }) for all events. Factory-created controls support the same callbacks through TabsEventExt. Existing cx.subscribe observers remain supported.
