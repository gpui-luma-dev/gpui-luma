SDK/Controls

Tabs

Switch between sections or destinations.

Basic use

Radix · integration snippet
use gpui::{Context, Subscription};
use gpui_luma::controls::tabs::TabsEvent;
use gpui_luma::controls::tabs::TabsItem;
use gpui_luma_look_radix as radix;

struct Example {
    control: gpui::Entity<gpui_luma::controls::tabs::Tabs>,
    active_tab: String,
    _subscription: Subscription,
}

impl Example {
    fn new(cx: &mut Context<Self>) -> Self {
        let control = radix::Tabs::new("settings")
            .items([TabsItem::new("account").label("Account"), TabsItem::new("appearance").label("Appearance")])
            .active("account")
            .spawn(cx);

        let subscription = cx.subscribe(&control, |app, _, event: &TabsEvent, cx| {
            if let TabsEvent::Change { tab_id, .. } = event {
                app.active_tab = tab_id.to_string();
                cx.notify();
            }
        });

        Self { control, active_tab: "account".into(), _subscription: subscription }
    }
}

Integration snippet, checked against the current SDK and Radix crates. cx is the initialized owner context. The example retains both the control and its subscription. Render self.control.clone() in the owner’s view.

SDK behavior & customization

Supports navigation-only items and retained panels. Choose panel retention and animation intentionally.

Relevant contracts: TabsRenderModel, TabsTemplateHandlers, TabsTemplateModifier, TabsTemplate.

Use the module’s template contract for structural changes. Builder modifiers and item templates vary by control.

Events

The callback updates application state. Retain the subscription for as long as the owner needs events; dropping it unsubscribes. cx.notify() requests an owner redraw.

Event / payloadApplication use
Change { tab_id: SharedString, label: SharedString }Switch the active application section.
Activate { tab_id: SharedString, label: SharedString }An item was activated; handle its application action.
Reactivate { tab_id: SharedString, label: SharedString }The already-active tab was activated again.
DropdownRequested { tab_id: SharedString, label: SharedString, bounds: Option<Bounds<Pixels>> }A tab requested its dropdown; bounds can anchor a menu.
ItemBoundsChanged { tab_id: SharedString, bounds: Bounds<Pixels> }An item’s bounds changed.
FocusChanged { focused: bool }Focus state changed.
ItemFocused { tab_id: SharedString, label: SharedString }An item received focus.

TabsEvent · Event definitions. Match the events you need; allow for other variants.

Look differences

Radix provides an adapter for this SDK role. Variant names, sizes, and styling options belong to the Look, not the SDK contract. Builders use ambient Look resolution unless you explicitly override it.

Radix variants: Line, Surface.
