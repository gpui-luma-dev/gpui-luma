Dock Splitter

A draggable boundary between dock regions.

Basic use

SDK · integration snippet
use gpui::{Context};
use gpui_luma::controls::dock_splitter::{DockSplitter, SplitterOrientation};

struct Example {
    control: gpui::Entity<gpui_luma::controls::dock_splitter::DockSplitter>,
    resize_delta: f32,
}

impl Example {
    fn new(cx: &mut Context<Self>) -> Self {
        let control = DockSplitter::new("sidebar-resize", SplitterOrientation::Vertical)
            .on_resize_delta(cx, |app, total_delta, cx| {
                app.resize_delta = total_delta;
                cx.notify();
            })
            .spawn(cx);

        Self { control, resize_delta: 0.0 }
    }
}

Integration snippet, checked against the current SDK and Radix crates. cx is the initialized owner context. The control retains its callbacks; callback owners are held weakly. Render self.control.clone() in the owner’s view.

SDK behavior & customization

Resize reports a total delta. The host applies it to the corresponding layout dimensions.

Relevant contracts: DockSplitterRenderModel, DockSplitterTemplateHandlers, DockSplitterTemplateModifier, DockSplitterTemplate.

Use the module’s template contract for structural changes. Builder modifiers and item templates vary by control.

Events

Callbacks follow the existing SDK event stream. Registrations append, hold the owner weakly, and live until the control is released. cx.notify() requests an owner redraw. Compound payloads are borrowed; scalar values are passed by value.

Event / payloadCallback
ResizeStart.on_resize_start(cx, |app, cx| { … })
Resize { total_delta: f32 }.on_resize_delta(cx, |app, total_delta, cx| { … })
ResizeEnd.on_resize_end(cx, |app, cx| { … })
FocusChanged { focused: bool }.on_focus_changed(cx, |app, focused, cx| { … })
HoverChanged { hovered: bool }.on_hover_changed(cx, |app, hovered, cx| { … })
EnabledChanged { enabled: bool }.on_enabled_changed(cx, |app, enabled, cx| { … })

Use .on_event(cx, |app, event, cx| { … }) for all events. Factory-created controls support the same callbacks through DockSplitterEventExt. Existing cx.subscribe observers remain supported.

.on_resize_delta handles the semantic Resize event. The existing .on_resize builder hook receives the Window during template input handling.
