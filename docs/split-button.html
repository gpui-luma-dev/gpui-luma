Split Button

An action face with an adjacent menu trigger.

Basic use

SDK · integration snippet
use gpui::{Context, Subscription};
use gpui_luma::controls::split_button::SplitButtonEvent;
use gpui_luma::controls::split_button::SplitButton;
use gpui_luma::infra::{menu_item::MenuItem, presenter::HasPresenter};

struct Example {
    control: gpui::Entity<gpui_luma::controls::split_button::SplitButton>,
    last_action: String,
    _subscription: Subscription,
}

impl Example {
    fn new(cx: &mut Context<Self>) -> Self {
        let control =
            SplitButton::new("save").label("Save").items([MenuItem::new("save-as").label("Save as")]).spawn(cx);

        let subscription = cx.subscribe(&control, |app, _, event: &SplitButtonEvent, cx| {
            match event {
                SplitButtonEvent::ActionClick => {
                    app.last_action = "save".into();
                }
                SplitButtonEvent::Select { item_id, .. } => {
                    app.last_action = item_id.to_string();
                }
                _ => return,
            }
            cx.notify();
        });

        Self { control, last_action: String::new(), _subscription: subscription }
    }
}

Integration snippet, checked against the current SDK and Radix crates. cx is the initialized owner context. The example retains both the control and its subscription. Render self.control.clone() in the owner’s view.

SDK behavior & customization

Aliases the PopupMenu engine. Handle ActionClick separately from menu Select events.

Events

The callback updates application state. Retain the subscription for as long as the owner needs events; dropping it unsubscribes. cx.notify() requests an owner redraw.

Event / payloadApplication use
ActionClickThe split action face was activated.
Select { item_id: SharedString, label: SharedString }An option or command was selected; use its stable ID.
OpenChanged { open: bool }Popup visibility changed.
DismissThe popup was dismissed.
FocusChanged { focused: bool }Focus state changed.
HoverChanged { hovered: bool }Pointer hover state changed.
EnabledChanged { enabled: bool }Enabled state changed.

SplitButtonEvent · Event definitions. Match the events you need; allow for other variants.

Look differences

No dedicated Radix factory is exported for this SDK module. Use the SDK contract shown here; integrate a custom template or theme where the module supports one. Do not assume Shadcn and Radix have matching factories.
